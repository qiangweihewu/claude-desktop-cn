# Claude Desktop CN v1.6.37

这一版聚焦两件事：把卡了上一次 macOS 发布的公证流程修稳，以及把"自定义兼容 API"的配置入口做得更顺手。

## 主要更新

### 1. 设置页新增「API 配置」导航项
- 设置侧边栏在「常规」之后多了一个独立的「API 配置」入口，所有用户都能直接看到。
- 之前自定义兼容 API 用户没有快速跳到完整配置页的入口，现在补齐了。

### 2. 自定义兼容 API 用户：常规页直接显示更换 API 面板
- 当 `user_mode === selfhosted` 时，「常规 → 用户模式」卡片下方会直接展开「更换自定义兼容 API」面板，可以原地填 Base URL / API Key 后保存切换。
- 减少了一次点击和一次页面跳转。

### 3. 修复「账号」标签内容错位
- 历史代码把 API 配置渲染在了 `case 'account'` 下，导致真正的账号页（邮箱、修改密码、退出登录、活跃会话）一直是死代码。
- 这次把 API 配置移到独立的 `apiConfig` section，「账号」标签恢复为账号页本身。

### 4. macOS 公证流程稳定性修复
- 公证 `--timeout` 从 90 分钟收紧到 30 分钟，避免 Apple 服务卡顿时 CI 空等 90 分钟。
- 公证步骤加 3 次重试 + 60 秒间隔，应对 Apple Notary 服务的偶发抖动，不再需要手动 re-run。
- 步骤超时上限从 100 分钟降到 45 分钟。
- 收窄 electron-builder 的 DEBUG 输出范围，日志更可读。

### 5. 打包过滤 `.bak` 备份文件
- `package.json` 的 `files` 字段新增 `!**/*.bak`，避免 `electron/bridge-server.cjs.bak` 这类备份被打入安装包。

## 验证

```bash
npm run build
```

CI 已自动构建 Windows 和 macOS 安装包。
